Claude Design

Let's create a design system.

A design system is the set of rules every screen follows. We decide them once, and Claude applies them everywhere.

What's in it
  • Type. One face for headlines, one for body, one for labels.
  • Colour. A primary, an accent for the key number, and neutrals.
  • Spacing. One scale for margins and gaps.
  • Components. Buttons, cards and charts, built the same way each time.

Why it matters: we work at the element level. Change a button, a colour or a gap once, and every screen updates. Every page we make after that looks like it came from the same organisation.

The prompt 
Help me create a design system for [my org], which works on [topic].
Before you build anything, ask me 3 short questions, one at a time: who it's for, the mood, and any brand colours or fonts I already use.
Then set up type, colour, spacing and components (buttons, cards, a stat block, a simple chart).
Show me a sample page that uses all of it.

Claude Design + a skill

Now let's add our build rules.

tailwind-design is a skill I wrote for Claude. Tailwind turns styling into shared tokens and utility classes, so every page and tool we build follows the same rules. The skill tells Claude which rules to hold to.

The four rules
  • Tokens first. Every colour, size and gap comes from a named token.
  • Readable contrast. Every text and background pair passes WCAG AA.
  • Flexbox first. Grid only when rows and columns both matter.
  • Nothing tiny. Body text and buttons stay at 16px or larger.
The prompt 
Here is our tailwind-design skill. Adapt the design system to follow it: give every colour, font size and spacing value a named token, fix any text and background pair below WCAG AA, and keep body text at 16px or larger.

Claude Code + Remotion skill

Now let's make it move.

What motion design is

Animation with a purpose: a chart that draws itself, a number that counts up, a scene that changes as the data changes.

Why it matters for climate and impact work

Most of our data is about change over time, and motion shows that change happening. Watching a line climb from 316 to 427 ppm sticks in a way a static chart rarely does, and a 20-second video travels on social channels where a report doesn't.

Remotion, plus a skill for Claude Code

Remotion is open source and turns React code into video. The Remotion skill gives Claude Code its craft rules: no linear easing, staggered entrances, and render, inspect, fix before handing over.

# Tailwind design ground rules

Apply these rules whenever writing, editing, or reviewing Tailwind classes.

## 1. Token-first, no arbitrary values

Colors, spacing, font sizes, and radii come from the theme, never from bracket syntax.

Bad: w-[137px], text-[#2c2c2c], mt-[18px]
Good: w-content, text-ink, mt-6

## 2. Use Tailwind's color palette

No gray-on-gray, no gray on pure white or black. Every text and background pair meets WCAG AA (4.5:1 for body text). No transparency on text.

## 3. Layout, flexbox first

Default to flex with gap. Use grid only when rows and columns both matter. Avoid absolute positioning unless nothing else works.

## 4. Type scale, nothing smaller than text-base

Body copy, labels, buttons and nav are text-base or larger. text-sm is for captions and fine print only.

## Applying this in a new project

Port the project's existing tokens into the Tailwind theme first, so token-first has real tokens to point at.
