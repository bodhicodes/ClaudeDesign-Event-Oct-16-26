# Project rules

- Use the design system in `tokens.css` for everything built in this project.
- Every colour, font size, spacing value and radius comes from a token. Don't add raw hex codes or pixel values. If a value is missing, add a token for it first.
- Follow the tailwind-design skill: WCAG AA contrast on every text and background pair, no transparency on text, flexbox first, and nothing smaller than 16px for body text, labels and buttons.
- Headlines use the sans font (Bricolage Grotesque). Body copy uses the serif (Newsreader).
- Marigold (`amber-300`) is for giving and for the single most important number on a screen. Use it once per screen.
