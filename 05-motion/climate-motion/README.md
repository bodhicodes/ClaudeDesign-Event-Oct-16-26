# climate-motion

The Remotion project behind both videos. `src/Root.tsx` registers two compositions, Planet and Keeling. The planet lives in `src/planet/`, the Keeling curve in `src/scenes/`, the NOAA data in `src/data.ts` and the colours and fonts in `src/theme.ts`.

```
npm install
npm run textures
npm run studio
```

Setup and the prompts that built it are in the [motion guide](../).
